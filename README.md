## 📖 About the Project

**CONNECT WITH ME** is a lightweight personal social-link hub that brings professional profiles, social media accounts, and developer community links together in one accessible interface.

Instead of sharing individual profile URLs, visitors can open a single page and choose the platform they want to visit.

The website is built with standard web technologies and is deployed on Netlify.

## ✨ Features

- **Centralized Profile Links:** Access multiple social, professional, and developer profiles from one page.
- **Professional Networking:** Quick access to LinkedIn and other professional profiles.
- **Developer Profiles:** Connect through GitHub, HackerRank, LeetCode, CodeChef, Code360, and GeeksforGeeks.
- **Social Media Integration:** Links to platforms such as Instagram, X, YouTube, Snapchat, Reddit, Threads, Pinterest, Discord, Twitch, and Tumblr.
- **One-Click Navigation:** Open the selected platform directly from its link card.
- **Link-Sharing Controls:** JavaScript-powered controls are provided for copying or sharing profile URLs.
- **Icon-Based Interface:** Font Awesome icons help visitors recognize platforms quickly.
- **Responsive Styling:** CSS-based layout adapts the page to different screen sizes.
- **Custom Branding:** Personal profile heading, favicon, typography, and styling.
- **Lightweight Deployment:** Static files can be hosted without a dedicated backend server.

The listed links and available interactions reflect the project source; individual third-party profiles may change independently.

## 🚀 Getting Started

### Prerequisites

You need:

- Git
- A modern web browser
- A code editor, such as Visual Studio Code

No package manager or build system is required for basic local use.

### 1. Clone the Repository

```bash
git clone https://github.com/pratikabhang/CONNECT-WITH-ME.git
cd CONNECT-WITH-ME
```

### 2. Run Locally

Open `index.html` directly in your browser.

Alternatively, use the VS Code **Live Server** extension to serve the project locally.

For example, if Python is installed, you can run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

Stop the server with `Ctrl+C`.

### 3. Customize Your Links

Open `index.html` and update the relevant profile URLs and labels.

The JavaScript file contains the navigation and link-sharing behavior. If you change a profile URL, update the corresponding URL used by its sharing control as well.

### 4. Customize the Design

Edit `styles.css` to change:

- Colors and gradients
- Typography
- Spacing and layout
- Link-card appearance
- Responsive behavior
- Hover and interaction states

Replace `icon.png` if you want to use a different favicon.

## 🌍 Deployment

The website is deployed on Netlify.

To deploy your own version:

1. Fork or clone the repository.
2. Customize the HTML, CSS, JavaScript, and favicon.
3. Push your changes to GitHub.
4. Import the repository into Netlify or connect it to an existing Netlify site.
5. Configure the publish directory as the repository root.
6. Deploy and verify the live website.

Because this is a static site, a Node.js build command is not required unless you add a build tool in the future.

**Live deployment:** [pratikabhang.netlify.app](https://pratikabhang.netlify.app/)

## 🔒 Security and Privacy

- Only include profile URLs that you intend to share publicly.
- Verify third-party URLs before publishing them.
- Avoid embedding passwords, API keys, or private tokens in client-side JavaScript.
- Remember that all HTML, CSS, and JavaScript delivered to a browser can be inspected by visitors.
- Keep external libraries and dependencies updated where applicable.
